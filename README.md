# islamnest.app

The support and download page for the IslamNest Android and iPhone apps. Plain HTML and CSS, no build step.

- `index.html`: app overview, store status, screenshots, features, home-screen steps, FAQ, support links.
- `delete-account/`: account deletion instructions (the URL to give Google Play).
- Store links must only be added once the apps are live in Google Play and the App Store.
- Screenshots in `assets/screens/` are real screens of islamnest.com at phone size.

The main site is https://islamnest.com.
